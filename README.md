# JS Runtime using [Rusty V8](https://github.com/denoland/rusty_v8)

A simple runtime for learning and exploring the V8 engine in Rust, and using it for running my [JSX framework](https://github.com/Maki325/framework-js).

It can handle getting a network request in Rust with the [`hyper`](https://github.com/hyperium/hyper), run the JS code generated by the JSX framework, and send the generated response back over the network, and even stream the response if there are async JSX Components present.

Implements:
 - Custom global function that can be called from JS (Required for JSX framework)
 - Handles `Promise` using `tokio`
 - `setTimeout`
 - `log`
 - Network handling with `hyper`
 - Support for streaming responses
